# Repository Guidelines

- This repository is the single source of truth for the user's curated skill list across all projects. The current entries in `skills.json` are authoritative; this repository stores only metadata and documentation.
- Use English for repository documentation, metadata descriptions, code comments, command-line help, and user-facing messages emitted by scripts.
- Before installing, updating, syncing, or previewing, read the [installation workflow](README.md#install) and [security requirements](README.md#security). For an installation, update, or sync, first confirm the target path and whether the user approves removing all project-scoped skills there. Do not ask again if this operation has already been explicitly approved.
- Before adding, migrating, or removing a skill, or changing task usage, read the [admission and maintenance requirements](README.md#admission-criteria). After modifications, run the required [validation checks](README.md#validation).
- When selecting a skill for a task or explaining how to use it, read [skill_maps.md](skill_maps.md).
- When searching for or recommending skills, use the user's quantitative options trading work as context and prioritize skills suited to quantitative research and trading development workflows. Give preference to authors with experience at internationally recognized investment banks, large hedge funds, quantitative trading firms, or market makers. For research workflow and plotting skills, also prioritize authors with relevant research, analysis, or visualization experience at large companies. Verify author backgrounds through public sources and include links; explicitly state when a background cannot be verified. Base final recommendations on the skill's content and fit for the actual task, treating author experience as an additional positive factor.
